PayTR: `threeDSMode: 'direct'` runs 3D Secure payments with a new card through the Direct API (your own card form, posted from the customer's browser) instead of the iFrame

<!-- docs -->
en: **[PayTR Direct API 3D Secure](/docs/providers/paytr):** with `threeDSMode: 'direct'`, `initThreeDSPayment()` takes the card from your own checkout form and returns a signed Direct API form instead of PayTR's iFrame.
tr: **[PayTR Direct API ile 3D Secure](/docs/providers/paytr):** `threeDSMode: 'direct'` ile `initThreeDSPayment()` kartı kendi ödeme formunuzdan alır ve PayTR iFrame'i yerine imzalı bir Direct API formu döndürür.
