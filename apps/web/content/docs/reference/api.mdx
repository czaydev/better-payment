The reference is generated with TypeDoc from the same source revision as this site.
It includes the main package, `client`, `testing`, `plugins` and every framework
adapter. Use its search to find exported functions, classes and types. The reference
is in English and is shared by both documentation languages.

Stable and beta deployments generate their own reference. Follow the version picker
before opening it so the API matches the package version you are using.

For integration walkthroughs, start with the [quick start](/docs/quick-start).
The [type overview](/docs/reference/types) explains the most common request and response shapes.

## For AI assistants

Each build also produces `/llms.txt`, an index of English and Turkish documentation,
and `/llms-full.txt`, the complete English documentation as Markdown. The index links
to clean Markdown copies of the individual pages. Beta deployments serve these files
under `/beta` and link to that version's documentation.

These files are generated from the docs, not maintained separately.
