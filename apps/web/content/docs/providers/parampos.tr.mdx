Parampos, Param'ın TurkPOS SOAP servisini kullanır.

## Yapılandırma [#configuration]

```typescript
import { betterPayment, parampos } from 'better-payment';

const payment = betterPayment({
  providers: {
    parampos: parampos({
      clientCode: process.env.PARAMPOS_CLIENT_CODE!,
      clientUsername: process.env.PARAMPOS_CLIENT_USERNAME!,
      clientPassword: process.env.PARAMPOS_CLIENT_PASSWORD!,
      guid: process.env.PARAMPOS_GUID!, // keep secret: callbacks are verified with it
      // baseUrl: defaults from mode (test-dmz.param.com.tr / posws.param.com.tr)
    }),
  },
});
```

## Tutarlar ve taksit [#amounts-and-installments]

- `price` → `Islem_Tutar`, `paidPrice` → `Toplam_Tutar` (taksit komisyonu dahil çekilen tutar). Tutarlar ondalık virgülle gönderilir.
- Taksitli ödemede `paidPrice`, Param oranlarınızdaki komisyonu içermelidir. Bunu `calculatePaidPrice()` ile hesaplayın (aşağıda); kütüphane oranları asla tahmin etmez.
- TRY `TP_WMD_UCD` kullanır; USD, EUR ve GBP `TP_Islem_Odeme_WD` kullanır (bkz. [Döviz ödemeleri](#foreign-currency-3d-secure)). Diğer para birimleri `failure` döner.

`paymentId` sipariş numaranızdır (`Siparis_ID`): verdiğiniz `conversationId` ya da üretilen alfanümerik bir numara.

## 3D Secure

```typescript
const init = await payment.parampos.initThreeDSPayment({
  ...paymentRequest,
  conversationId: 'ORDER123',
  installment: 1,
  callbackUrl: 'https://yoursite.com/api/pay/parampos/payment/complete-3ds',
});
// Render init.threeDSHtmlContent (UCD_HTML)
```

Param, `callbackUrl` adresine `md`, `mdStatus`, `orderId`, `islemGUID`, `islemHash`, … alanlarını POST eder:

```typescript
const result = await payment.parampos.completeThreeDSPayment(callbackBody);
```

1. `islemHash`, **yapılandırmanızdaki GUID** ile doğrulanır. Callback'in içindeki bir GUID yok sayılır.
2. `mdStatus` `1` olmalıdır.
3. Ödeme `TP_WMD_Pay` ile tamamlanır. Yalnızca Param bir `Dekont_ID` döndürdüğünde `success` sayılır.

## Döviz ödemeleri (3D Secure) [#foreign-currency-3d-secure]

`TP_WMD_UCD` yalnızca TRY kabul eder. USD, EUR ve GBP ödemeleri `Doviz_Kodu`
1001, 1002 ve 1003 ile `TP_Islem_Odeme_WD` kullanır ve HTML formu yerine bir
yönlendirme adresi döner:

```typescript
const init = await payment.parampos.initThreeDSPayment({
  ...paymentRequest,
  currency: 'USD',
  conversationId: 'ORDER123',
  callbackUrl: 'https://yoursite.com/api/pay/parampos/payment/complete-3ds',
});

if (init.redirectUrl) {
  window.location.assign(init.redirectUrl);
}
```

Param sonucu `callbackUrl` adresine `TURKPOS_RETVAL_*` form alanları olarak
POST eder. `completeThreeDSPayment()`, `TURKPOS_RETVAL_Hash` değerini
`clientCode` ve GUID'inizle doğrulamadan `success` döndürmez:

```typescript
const result = await payment.parampos.completeThreeDSPayment(callbackBody);
// result.amount and result.currency come from the verified callback
```

- Hash; `CLIENT_CODE`, `TURKPOS_RETVAL_GUID`, `TURKPOS_RETVAL_Dekont_ID`,
  `TURKPOS_RETVAL_Tahsilat_Tutari`, `TURKPOS_RETVAL_Siparis_ID` ve
  `TURKPOS_RETVAL_Islem_ID` alanlarını kapsar. GUID, yapılandırmanızdaki değer
  olmalıdır.
- `success` ayrıca `TURKPOS_RETVAL_Sonuc` değerinin sıfırdan büyük olmasını,
  `TURKPOS_RETVAL_Islem_ID` değerinin sıfır olmamasını ve
  `TURKPOS_RETVAL_Dekont_ID` değerinin pozitif olmasını gerektirir. Yalnızca
  dönüş adresine gelinmesi bir onay değildir.
- Tutar bir kez biçimlendirilir; gönderilen ve hash'lenen dize aynıdır
  (`100` ve `100.00` ikisi de `100,00` olur).
- Bu ödemelerde taksit desteklenmez (`TP_Islem_Odeme_WD` içinde `Taksit` alanı
  yoktur); 1'den büyük taksit sayısı reddedilir.
- İade ve iptal desteklenmez: Param'ın para birimine duyarlı bir iade mesajı
  yoktur; bu nedenle `refund()` ve `cancel()`, TRY mesajını göndermek yerine
  hata döner. Döviz ödemelerini Param panelinden iade edin.
- `cancel()` çağrısında `currency` verilmezse mevcut TRY davranışı korunur;
  TRY dışındaki her ödeme için `currency` verin ki çağrı reddedilsin.

## İade, iptal ve durum sorgusu [#refund-cancel--status]

```typescript
await payment.parampos.refund({ paymentId: 'ORDER123', price: '50.00', currency: 'TRY', ip: '1.2.3.4' });

// Same-day void. Param needs the full amount; without price it is looked up.
await payment.parampos.cancel({ paymentId: 'ORDER123', ip: '1.2.3.4' });

const status = await payment.parampos.getPayment('ORDER123'); // TP_Islem_Sorgulama4
```

## Taksit [#installments]

`installmentInfo()`, `BIN_SanalPos` (kartın hangi kart programına ait olduğu) ile `TP_Ozel_Oran_SK_Liste`'yi (müşteriye yansıyan oranlarınız) birleştirir ve kullanılabilir taksit sayılarını Param'ın toplam tutarlarıyla döner:

```typescript
const info = await payment.parampos.installmentInfo({ binNumber: '435508', price: '100.00' });
// installmentPrices: [
//   { installmentNumber: 1, totalPrice: 101.75, installmentPrice: 101.75, commissionRate: 1.75 },
//   { installmentNumber: 3, totalPrice: 104.10, installmentPrice: 34.70, commissionRate: 4.1 },
//   ...
// ]
```

Taksitle çekim yapmak için `paidPrice`'ı (Toplam_Tutar) aynı şekilde hesaplayın:

```typescript
const paidPrice = await payment.parampos.calculatePaidPrice({
  binNumber: '435508',
  price: '250.00',
  installment: 3,
}); // '260.25'

await payment.parampos.initThreeDSPayment({ ...order, price: '250.00', paidPrice, installment: 3 });
```

- Toplam: `Toplam_Tutar = price + price × oran / 100`, kuruşa yukarı yuvarlanır (yarım ve üstü).
- Oranı negatif olan taksit sayıları (Param'da "kullanılamaz") listelenmez; `calculatePaidPrice()` bunlar için `ValidationError` fırlatır.
- `BIN_SanalPos` `DKK = 1` döndürdüğünde "Diğer Banka Kartları" oranları uygulanır.
- `getInstallmentRates()`, tüm kart programlarının ham oran tablosunu döner.
