---
title: Hata Mesajları için Dil Desteği
description: Müşterilere ödemenin neden başarısız olduğunu kendi dillerinde söyleyin.
---

Sağlayıcılar hata mesajlarını kendi ifadeleri ve dilleriyle, çoğu zaman teknik terimlerle yazar ("Do not honour", "Invalid merchant"). `localizedErrors` plugin'i başarısız sonuçların `errorMessage` alanını, normalize [hata koduna](/docs/reference/error-codes) göre seçilen, müşteriye yönelik bir mesajla değiştirir. İngilizce, Türkçe, Almanca ve Rusça mesajlar dahildir.

## Kurulum [#setup]

```typescript
import { betterPayment, iyzico } from 'better-payment';
import { localizedErrors } from 'better-payment/plugins';

const payment = betterPayment({
  providers: { iyzico: iyzico({ /* ... */ }) },
  plugins: [localizedErrors({ locale: 'tr' })],
});

const result = await payment.createPayment(request);
result.code;            // 'INSUFFICIENT_FUNDS'
result.errorMessage;    // 'Kartınızın bakiyesi veya limiti yetersiz. Başka bir kart deneyin.'
result.providerMessage; // the provider's own message, for your logs
```

Yalnızca `code` alanı olan sonuçlar değişir: başarısız sonuçlar ve `NETWORK_ERROR` ile gelen `pending` sonuçlar. Sağlayıcının metni loglarınız ve destek ekibiniz için `providerMessage` alanında kalır.

## Seçenekler [#options]

| Seçenek | Varsayılan | Açıklama |
| ------- | ---------- | -------- |
| `locale` | `'en'` | Varsayılan dil |
| `fallbackLocale` | `'en'` | Bir dilde eksik olan kodlar için kullanılan dil |
| `messages` | — | Dile göre ek diller ya da kendi ifadeleriniz |
| `detectLocale` | `true` | HTTP handler'ın her yanıtının dilini istekten seçer |

## Kendi ifadeleriniz ve ek diller [#your-own-wording-and-more-languages]

```typescript
localizedErrors({
  locale: 'tr',
  messages: {
    tr: { INSUFFICIENT_FUNDS: 'Bakiyeniz yetersiz, lütfen başka bir kart deneyin.' },
    es: {
      INSUFFICIENT_FUNDS: 'Fondos insuficientes. Intente con otra tarjeta.',
      CARD_DECLINED: 'Su banco rechazó el pago.',
    },
  },
});
```

Bir dilde eksik olan kod `fallbackLocale` diline düşer. Mesajı olmayan bir `locale` `ConfigurationError` fırlatır.

## HTTP handler'da isteğe göre [#per-request-in-the-http-handler]

[HTTP handler](/docs/concepts/handler) her yanıtı kendi isteğine göre çevirir; varsayılan olarak `Accept-Language` başlığından: `tr-TR,tr;q=0.9` Türkçe alır, desteklenmeyen bir dil `locale` dilini alır. Bir `Idempotency-Key` için tekrar gönderilen yanıtlar da yeni isteğe göre çevrilir. Dili başka bir yolla seçmek için bir fonksiyon verin ya da algılamayı kapatın:

```typescript
// Language from a query parameter: /api/pay/iyzico/payment?lang=tr
localizedErrors({
  detectLocale: (request) => new URL(request.url, 'http://localhost').searchParams.get('lang') ?? undefined,
});

// Always Turkish
localizedErrors({ locale: 'tr', detectLocale: false });
```

Handler'ın kendi hata yanıtları (404, 403, geçersiz gövde) geliştiriciler içindir ve İngilizce kalır.

## Kodunuzda [#in-your-code]

Kodda çağırdığınız işlemler `locale` dilini kullanır. Başka bir dil için ya da plugin hook'ları olmadan çalışan sağlayıcıya özel metotların (iyzico ödeme formu, abonelikler) sonuçları için `payment.errors` kullanın:

```typescript
payment.errors.message('EXPIRED_CARD', 'en');   // "Check your card's expiry date."
payment.errors.translate(checkoutResult, 'tr'); // the result, with errorMessage in Turkish
payment.errors.locales;                         // ['en', 'tr', ...]
```

## Diğer plugin'lerin hata kodları [#error-codes-of-other-plugins]

Diğer plugin'lerin `$ERROR_CODES` içinde tanımladığı kodlar da çevrilir. Plugin'in kendi mesajı varsayılandır; çevirileri `messages` içinde ekleyin:

```typescript
plugins: [
  blockList({ bins: ['400000'] }), // declares BLOCKED_BIN in $ERROR_CODES
  localizedErrors({
    locale: 'tr',
    messages: { tr: { BLOCKED_BIN: 'Bu kart kullanılamaz.' } },
  }),
],
```

Önce plugin'in kodu (`errorCode` içinde), sonra normalize `code` aranır.

## better-payment'e dil eklemek [#add-a-language-to-better-payment]

Yerleşik mesajlar `packages/better-payment/src/plugins/localized-errors/` altında, her dil için bir dosyada ve `Record<PaymentErrorCode, string>` tipindedir: bir kodu eksik olan dosya derlenmez.

1. `en.ts` dosyasını dilin adıyla (`de.ts`) kopyalayın ve mesajları çevirin. Mesajları kısa, müşteriye yönelik ve teknik ayrıntısız tutun.
2. Dili `localized-errors/index.ts` içindeki `errorMessages` nesnesine ekleyin.
3. Bir pull request açın. Mevcut test her dilde her kodun mesajı olduğunu kontrol eder.
