Her adapter ayrı bir import'tur ve hiç bağımlılığı yoktur; yalnızca kullandığınız yüklenir.

| Framework | Import | Fonksiyon |
| --- | --- | --- |
| [Next.js](/docs/integrations/nextjs) | `better-payment/next` | `toNextJsHandler` |
| [React Router](/docs/integrations/react-router) | `better-payment/react-router` | `toReactRouterHandler` |
| [Express](/docs/integrations/express) | `better-payment/express` | `toExpressHandler` |
| [Fastify](/docs/integrations/fastify) | `better-payment/fastify` | `toFastifyPlugin` |
| [Hono](/docs/integrations/hono) | `better-payment/hono` | `toHonoHandler` |
| [Elysia](/docs/integrations/elysia) | `better-payment/elysia` | `toElysiaHandler` |
| [Node.js](/docs/integrations/node) | `better-payment/express` | `toNodeHandler` |
| [Cloudflare Workers](/docs/integrations/cloudflare-workers), [Deno](/docs/integrations/deno), [Bun](/docs/integrations/bun) | `better-payment` | `toFetchHandler` |

Tüm adapter'lar:
- JSON ve form-urlencoded gövdeleri (banka callback'leri) handler'a geçirir
- PayTR'nin `OK` yanıtını düz metin olarak gönderir
- yönlendirmelerin (`callbackRedirect`) `Location` başlığını korur

Onları handler'ın `basePath`'i altına bağlayın (varsayılan `/api/pay`). Listede olmayan bir framework için [diğer framework'ler](/docs/concepts/handler#frameworks) bölümüne bakın.

## Tembel başlatma [#lazy-initialization]

Tüm adapter'lar ödeme nesnesini (ya da handler'ını) döndüren bir fonksiyonu da kabul eder. Fonksiyon her istekte çağrılır, böylece örneği ilk kullanımda oluşturabilirsiniz:

```typescript
const createPayment = () => betterPayment({ /* ... */ });

let instance: ReturnType<typeof createPayment> | undefined;
const getPayment = () => (instance ??= createPayment());

app.all('/api/pay/*path', toExpressHandler(getPayment));
```

## İstek gövdesi boyutu [#request-body-size]

<Since version="0.8.1" />

Express, Node.js ve fetch tabanlı adapter'lar bir istek gövdesinin en fazla 1 MiB'ını okur ve daha büyükleri için `413` döner. Banka callback'leri birkaç kB'tır. Sınırı `toExpressHandler`, `toNodeHandler` veya `toFetchHandler` üzerinde `maxBodySize` (bayt) ile değiştirin:

```typescript
app.all('/api/pay/*path', toExpressHandler(payment, { maxBodySize: 64 * 1024 }));
```

Fastify kendi `bodyLimit` ayarını uygular (varsayılan 1 MiB).
