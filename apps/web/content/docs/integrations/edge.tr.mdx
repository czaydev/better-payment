`better-payment`'in hiç runtime bağımlılığı yoktur ve yalnızca web standardı API'leri kullanır: `fetch`, WebCrypto (`crypto.subtle`), `TextEncoder` ve `atob`/`btoa`. Aynı paket şu ortamlarda çalışır:

- Node.js 20+
- Vercel Edge Functions ve `runtime = 'edge'` kullanan Next.js route'ları
- Cloudflare Workers
- Deno ve Deno Deploy
- Bun

Her sürüm Vercel Edge Runtime VM'inde test edilir. Bu VM'de `Buffer`, `process` ya da `require` yoktur. Test, dört sağlayıcının hepsi için orada istekleri imzalar ve callback'leri doğrular; sonuçları Node.js'te hesaplanan değerlerle karşılaştırır.

Her ortamın tam örnekli kendi sayfası var: [Cloudflare Workers](/docs/integrations/cloudflare-workers), [Deno](/docs/integrations/deno) ve [Bun](/docs/integrations/bun). [Hono](/docs/integrations/hono) ve [Elysia](/docs/integrations/elysia) için ayrı adapter'lar var.

## Next.js (edge)

[Next.js route handler'ı](/docs/integrations/nextjs) değişmeden çalışır. Yalnızca runtime'ı değiştirin:

```typescript
// app/api/pay/[...path]/route.ts
export const runtime = 'edge'; // or 'nodejs'
```

## Edge ve serverless ortamlarda idempotency [#idempotency-on-edge-and-serverless]

Varsayılan idempotency deposu, tekrar eden callback ve `Idempotency-Key` kayıtlarını **bellekte** tutar. Edge ve serverless platformlarda her isolate'in ya da örneğin kendi belleği vardır; bu yüzden yalnızca aynı isolate'e gelen istekleri tekilleştirir. Canlı ortamda [paylaşımlı bir depo](/docs/concepts/handler#duplicate-callbacks-and-idempotency-key) verin:

- **Upstash Redis** (HTTP tabanlı, her edge ortamında çalışır): `setIfAbsent` için `SET key value EX ttl NX`.
- **Cloudflare:** Durable Objects ya da D1 (`INSERT ... ON CONFLICT DO NOTHING`). Workers KV nihai tutarlıdır (eventually consistent) ve atomik `setIfAbsent`'i sağlayamaz.

## Özel fetch [#custom-fetch]

Sağlayıcı API çağrıları `globalThis.fetch` kullanır. Kendi uygulamanızı verin; örneğin istekleri bir proxy üzerinden geçirmek ya da testlerde taklit etmek için:

```typescript
betterPayment({
  fetch: (input, init) => fetch(input, { ...init, keepalive: true }),
  providers: { /* ... */ },
});
```
