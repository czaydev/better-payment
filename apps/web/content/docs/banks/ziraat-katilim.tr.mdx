Ziraat Katılım, [QNB](/docs/banks/qnb) ile aynı PayFor altyapısını kullanır; bu yüzden `ziraatKatilim()` QNB sağlayıcısını paylaşır. Farklar adresler, kurum kodu (`mbrId`) ve callback hash'idir.

<Callout type="warn">
  Henüz bir test mağazasıyla doğrulanmadı: herkese açık bir test mağazası yok. Test sunucusuna ulaşıldı ve beklenen cevabı verdi (bilinmeyen üye işyeri), ama ödeme denenmedi. Canlıya geçmeden önce küçük bir tutarla test edin.
</Callout>

## Yapılandırma [#configuration]

```typescript
import { betterPayment, ziraatKatilim } from 'better-payment';

const payment = betterPayment({
  providers: {
    ziraatkatilim: ziraatKatilim({
      mbrId: process.env.ZIRAAT_KATILIM_MBR_ID!, // institution code (Kurum kodu)
      merchantId: process.env.ZIRAAT_KATILIM_MERCHANT_ID!,
      userCode: process.env.ZIRAAT_KATILIM_API_USER!,
      userPass: process.env.ZIRAAT_KATILIM_API_PASSWORD!,
      merchantPass: process.env.ZIRAAT_KATILIM_STORE_KEY!, // 3D key
      // secureType?: '3DModel' | '3DPay' (default '3DModel')
      // baseUrl: defaults from mode (payfortestziraatkatilim.cordisnetwork.com / vpos.ziraatkatilim.com.tr)
    }),
  },
});
```

Tüm değerler Ziraat Katılım'dan alınır. `merchantPass` yalnızca hash'lerde kullanılır ve hiç gönderilmez; API şifresi de 3D formuna konmaz. `secureType`, üye işyerinizin 3D modeliyle aynı olmalıdır.

`paymentId` sipariş numaranızdır: verdiğiniz `conversationId` ya da üretilen bir numara (harf, rakam, `-` veya `_`).

## Ödemeler [#payments]

3D'siz satış, 3D Secure, iade, iptal ve durum sorgusu [QNB](/docs/banks/qnb)'deki gibi çalışır; istekler `/MPI/Default.aspx` adresine gider. XML API cevabı `Key=Value;;` biçiminde metindir; sağlayıcı bunu QNB'nin XML cevabı gibi okur.

```typescript
const init = await payment.ziraatkatilim.initThreeDSPayment({
  ...paymentRequest,
  conversationId: 'ORDER123',
  callbackUrl: 'https://yoursite.com/api/pay/ziraatkatilim/payment/complete-3ds',
});

// In the callback route
const result = await payment.ziraatkatilim.completeThreeDSPayment(callbackBody);
```

## Callback hash'i [#callback-hash]

`ResponseHash`, üye işyeri numaranız ve `merchantPass` ile kontrol edilir:

- `3DModel`: `base64(SHA1(MerchantID + MerchantPass + OrderId + ResponseRnd))`
- `3DPay`: `base64(SHA1(MerchantID + MerchantPass + OrderId + AuthCode + ProcReturnCode + ResponseRnd))`

`3DModel` hash'i 3D sonucunu kapsamaz; bu yüzden ödemeyi bankanın `3DModelPayment` cevabı belirler. `3DPay` callback'i sipariş sorgusuyla doğrulanır. Hash'i geçersiz bir callback `INVALID_HASH` olarak reddedilir; `paymentId` yalnızca bankanın doğruladığı bir ödemede doldurulur.

<Callout type="info">
  BIN ve taksit sorgusu desteklenmez: `binCheck()` ve `installmentInfo()` `NOT_SUPPORTED` fırlatır.
</Callout>
