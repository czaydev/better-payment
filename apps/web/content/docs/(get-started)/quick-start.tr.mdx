## 1. Ödeme nesnesini oluşturun [#1-initialize-betterpayment]

```typescript
import { betterPayment, iyzico } from 'better-payment';

export const payment = betterPayment({
  mode: 'sandbox', // sandbox URLs and provider test modes; default is 'production'
  providers: {
    iyzico: iyzico({
      apiKey: process.env.IYZICO_API_KEY!,
      secretKey: process.env.IYZICO_SECRET_KEY!,
    }),
  },
});
```

## 3. 3D Secure'u başlatın [#3-start-3d-secure]

```typescript
const init = await payment.initThreeDSPayment({
  ...request,
  callbackUrl: 'https://yoursite.com/api/pay/iyzico/payment/complete-3ds',
});

if (init.status === 'pending') {
  // Render init.threeDSHtmlContent in the browser
  // (or redirect to init.redirectUrl when the provider returns one)
}
```

## 4. 3D Secure'u tamamlayın [#4-complete-3d-secure]

Banka sonucu `callbackUrl` adresine POST eder. Bu POST gövdesini olduğu gibi geçirin:

```typescript
const result = await payment.completeThreeDSPayment(callbackBody);

if (result.status === 'success') {
  // mark the order as paid
}
```

Kütüphane callback'i sizin kimlik bilgilerinizle kontrol eder ve sağlayıcı gerektiriyorsa ödemeyi tamamlar. Sahte ya da başarısız bir callback her zaman `failure` döner. [HTTP handler](/docs/concepts/handler) bunu sizin için yapar.

## 5. Sonuçları işleyin [#5-handle-results]

| status | anlamı |
|--------|---------|
| `success` | Sağlayıcı tarafından onaylandı |
| `failure` | Reddedildi; `errorCode` / `errorMessage` alanlarına bakın |
| `pending` | Müşteri bekleniyor **ya da** sonuç bilinmiyor (`errorCode: 'NETWORK_ERROR'`) |
| `cancelled` | İptal edildi veya tamamen iade edildi (durum sorguları) |

<Callout type="warn">
  `NETWORK_ERROR` durumunda ödeme yine de gerçekleşmiş olabilir. Yeniden denemeden önce `getPayment(paymentId)` ile kontrol edin. Ödeme, iade ve iptal istekleri asla otomatik olarak tekrarlanmaz.
</Callout>

## Birden fazla sağlayıcı kullanmak [#using-multiple-providers]

```typescript
const payment = betterPayment({
  providers: {
    iyzico: iyzico({ /* ... */ }),
    paytr: paytr({ /* ... */ }),
  },
  defaultProvider: 'iyzico',
});

await payment.createPayment(request);                 // default provider
await payment.paytr.initThreeDSPayment(paytrRequest); // specific provider
await payment.use('paytr').getPayment('ORDER123');
```

## Siparişleri olaylarla güncelleyin [#update-orders-with-events]

Her sonucu tek tek kontrol etmek yerine [ödeme olaylarını](/docs/concepts/events) dinleyin. Olaylar her sağlayıcı ve akış için, sonuç sağlayıcı tarafından doğrulandıktan sonra yayınlanır:

```typescript
payment.on('payment.succeeded', async (event) => {
  await orders.markPaid(event.conversationId, event.paymentId);
});

payment.on('payment.failed', async (event) => {
  await orders.markFailed(event.conversationId, event.code);
});
```
